# 验证报告：API 主流程（2026-09-21）

环境：Windows 11 x64，.NET SDK 10.0.401，Windows App SDK 2.5.1。已固定官方 Operations／Pilot OpenAPI。未提供实例凭据，**未发送真实业务 API 请求，未进行实例联调**。

## 构建与行为测试

Release 自包含目录发布成功，Core、Infrastructure、WinUI App 编译通过。完整可执行测试 **49 项通过**，包括原有 36 项回归及新增 13 项 API／合并测试。原先“所有 API 禁用”的断言已更新为已文档化能力可接入、旧未核实适配器拒绝写入。

新增覆盖：

- 机场 ICAO／IATA 别名导入、重复别名拒绝、旧 CSV 快照转换为 API 身份。
- 嵌入规范 SHA-256 与固定文档一致；航线新增使用整数关联 ID，本地引用仅用于预览和依赖编排。
- 20,000 条快照三方合并，保留行身份、独立本地编辑和远端编辑。
- 机型分步创建、稀疏 PUT、未知列不进入 JSON、字段长度和类型约束。
- 机场远端 ID 寻址、container_ids:[] 清空、航路／航线起降不可变、UTC 秒数保留。
- 航线机型集合、飞机更换机型、跨 Jumpseat 类型转换的阻止规则。
- 冲突保留及重复刷新不清除未解决冲突。
- OAuth form-urlencoded、Client Credentials、实际 expires_in 与令牌缓存。
- 飞机读取遍历机型、单条响应包装解析。
- 创建 ID 在补充 PUT 前持久化；PUT 超时后恢复仅回读，不重复 POST。
- 软删除即使 GET 返回 404 也不自动宣告成功。
- 修改冲突不发送 PUT；500 写入不重试；诊断隐藏令牌字段。
- API 元数据及语言切换不改变 CSV 导出字节。

原有回归仍覆盖 CSV 特殊字符、前导零、缺列／空值、拆分、显式删除、机型依赖、撤销／恢复、SQLite／DPAPI、401／403、429、取消、部分成功、存储失败、语言键及占位符一致性。

本机测量：20,000 行规划＋校验约 **121 ms**；API 快照三方合并约 **107 ms**。这些是本机数据处理时间，不包含真实网络耗时，不是性能保证。
