# 测试报告

本文记录当前版本检查了什么、结果如何，以及还有哪些没有验证。各轮的详细验收过程保存在 [历史记录](history/TEST-REPORT-2026-09-21-to-2026-10-19.md)。

**所有检查都使用隔离的合成数据。** 数据库位于新建的 GUID 目录或测试专用的临时目录；窗口程序通过 `VAMSYS_DATA_DIR` 指定数据目录。请求测试使用模拟 HTTP 或本地假服务器，不连接真实 vaMSYS，也不读取或修改用户真实的工作区。**目前还没有使用真实航空公司账号完成联调。**

**215 项全部通过。** 其中“真实 v3 旧程序拒绝 v4 数据库”一项需要本机保留的旧程序（`artifacts/step5-v3-baseline`），没有该基线的机器上为 214 项。

| 撤销历史 | 3 个种子各 1,000 次随机操作与全快照对照、结构步骤、字段顺序 |

| 审阅与批量 | 资源分组、样本限制、依赖暂缓、全局阻止、内容键（含防碰撞和缓存）、批量范围与无变化预览 |

## 尚未验证或已知问题

- **真实账号联调。** 没有用真实航空公司账号完成。官方文档未说明清楚的操作仍然禁用，见 [API 支持情况](API-CONTRACTS.md)。
- **单元格新外观。** 平时显示文本、编辑时显示输入框的样式，没有人工逐项查看明暗主题和高对比度下的效果。
- **`test-localization-ui.ps1`。** 该脚本是无 BOM 的 UTF-8，PowerShell 5.1 无法正确读取其中的中文。改用带 BOM 的副本运行后，新旧版本都在同一处失败：机型对话框中点击“Apply to drafts”时，自动化 Invoke 返回 Unrecognized error。因此这是脚本原有的问题，需要单独修复。
- **`scripts/build.ps1`。** 需要 PowerShell 7；在 Windows PowerShell 5.1 下同样因为编码无法解析。

## 复现

~~~powershell
# 全部自动测试
./.tools/dotnet/dotnet.exe run --project tests/VamSys.Tests/VamSys.Tests.csproj -c Release -p:RestoreLockedMode=true

# 正式包与 QA 包（会先运行全部测试，再检查包内容）
./scripts/build.ps1 -Publish
./scripts/build.ps1 -Publish -UiVerification
~~~

窗口脚本需要可操作的 Windows 桌面，运行前要关闭正在使用的 FlightOps Desk。各脚本的参数见 [Tests 项目说明](../tests/VamSys.Tests/README.md)。
