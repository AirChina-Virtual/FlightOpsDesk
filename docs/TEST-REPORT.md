## 关闭竞态

关闭状态在第一次等待前冻结编辑和命令；重复关闭不启动新保存。实际 SQLite 屏障与原审核复现结合，验证最后接受的编辑落盘，冻结后编辑不能改变草稿。

实际窗口使用系统 WM_CLOSE，验证等待期间修改、新操作和重复关闭均被拒绝，注入保存失败后交互恢复，接受新编辑后再次关闭成功，重新打开数据库读到最后接受的值。直接 Window.Close 绕过可取消事件，因此 QA 已明确采用系统消息模拟用户关闭。运行任务、模态框或交互操作未完成时拒绝关闭。

## v3 存储与恢复

- 旧格式和 v2 迁移、WAL 一致备份、历史任务、候选 ID、保存版本和撤销保留。

## 真实进程中断

父测试进程保留模拟远端状态，经命名管道响应子进程请求。子进程持有独立 SQLite 及同目录锁，在明确屏障被终止，再启动新子进程恢复：

| 屏障 | 断言 |
|---|---|
| Running 检查点提交前 | 无写请求，磁盘 Pending；恢复可首次执行 |
| Running 检查点提交后／POST 发出前 | 保守 Unknown，恢复不补发 |
| POST 返回 ID 提交前 | 远端已创建、磁盘无 ID；恢复不再次 POST |
| POST 返回 ID 提交后 | 返回 ID 和创建步骤保留；补充 PUT 不自动补发 |
| PUT 返回后、步骤检查点提交前 | 回读匹配后完成，不重发 POST／PUT |
| 重基线事务提交前 | 磁盘任务未成功、资源未重基线；恢复回读后一起提交 |
| 重基线事务提交后 | 磁盘成功与快照一致；重启跳过成功项 |
| 迁移事务提交前／后 | 分别保持完整旧库／完整 v2；无业务请求 |

连续恢复检查写次数不增加；模拟远端经独立修复后，正确候选或已有 ID 可通过回读完成。成功项保留远端 ID、未知 CSV 列与快照，清理相应撤销历史。共 10 项实际进程场景；不会结束用户程序，只终止本测试启动并持有的子进程。
