## 继续禁用的边界

- 飞机移动混合其他字段、SimBrief 编辑、weight_unit 写入与 lbs 换算。
- 空航线机队集合、jumpseat 集合修改、进入／离开 jumpseat 的类型转换。
- 既有机队参数改绑、解绑、集合替换及参数独立 CRUD。
