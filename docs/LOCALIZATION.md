# 多语言实现与维护

支持简体中文（默认）和英文。在“连接与设置 / Connection & settings”的语言选择器中即时切换，不重启、不提交草稿。语言偏好保存在当前数据目录 SQLite 的 `app_settings` 表，对全部工作区生效。无设置或无效值回退简体中文。

## 文案与数据边界

- `VamSys.Core/Resources/Strings.resx` 是中文基础资源，`Strings.en-US.resx` 是英文资源。现有 `Text_…` 键为固定标识，修改翻译时保留键；新文案建议采用有意义的语义键。禁止根据修改后的文字重新生成现有键。
- `ILocalizationService` 负责资源查找、显示文化和语言事件，业务层不读取当前界面语言。参数按名称匹配，替换仅进行一遍，用户输入中的花括号不会再被解释。
- 官方表头、字段名、枚举数据值、ID、用户机型名称、备注和未知 CSV 列不翻译。Windows 原生系统界面遵循系统语言。
- 数量和任务日期显式使用显示文化；业务解析和 CSV 格式保留原契约。不会改动进程的全局 CultureInfo。
- 新任务与校验信息使用 `MessageDescriptor`（代码与类型化命名参数），任务执行判断使用 `JobStatus`，不比较已翻译的文本。
- 历史 `Message` / `Status` 字段保留。已知固定提示按资源键显示，无法识别的动态或外部信息原样保留；不从文本猜测远端结果。
- 缺失资源回退中文，完全未知的键显示方括号标识；应用在数据目录的 `localization.log` 记录缺失键，不写入参数值或凭据。

## 界面更新与兼容

语言切换只更新显示属性。WinUI 控件的本地化注册保存在附加依赖属性中，以避免原生控件仍存在时托管包装对象被回收导致停止更新。服务只保留弱引用；脱离页面的控件可回收。

数据页面按工作区及资源保留搜索、筛选、排序、选中行和水平／垂直滚动位置。连接设置页面在会话内保留未保存输入，Secret 不因语言切换而写入数据库。切换时不新增撤销记录、不发请求、不重新执行任务。

语言入口位于设置页面，模态导入映射及确认窗口打开时不能操作该入口。已有对话框不会因语言设置而被重建。

新增 `app_settings` 表采用 `CREATE TABLE IF NOT EXISTS`，不更改现有工作区或凭据表。JSON 新增字段向后兼容；旧工作区无需手动转换。

## 验证入口

- `scripts/build.ps1 -Publish`：行为回归与自包含发布，包含英文卫星程序集。
- `scripts/test-localization-ui.ps1 -DataDirectory <新的隔离目录>`：真实 WinUI 双向切换、未保存输入、筛选选择、机型选择及删除恢复。运行前关闭本程序的其他实例。
- 测试覆盖资源键／占位符一致、显示文化隔离、历史消息、CSV 字节一致、业务结果一致以及执行中切换语言不重复写入。

本轮不增加在线能力，不改变 CSV/API 契约，也不提供自动翻译或联网语言包。
