# FlightOps Desk 使用指南

## 使用

解压 Windows 11 x64 程序包（已包含所需运行库），运行目录中的 `FlightOpsDesk.exe`。请保留整个目录。

1. 新建 VA 工作区，在“连接与设置”填写 Orwell 配置的 Operations Client ID 和 Secret，保存后测试连接。服务器地址固定为官方地址。
2. 点击“从 API 刷新”读取五类资源。飞机通过机型列表遍历获取。所有数据读取成功后才更新本地原始副本；中途失败或取消时，保留原来的数据。
3. 修改单元格或多选后应用批量规则，预览后写入草稿。在在线工作区导入 CSV 后，先生成待检查的修改，不会直接覆盖从服务器读取的原始数据；已有 ID 的记录需要先刷新核对。
4. 点击“审阅并提交”，核对目标 VA、字段差异及请求步骤。未在当前工作区回读验证的操作每次最多 3 条样本，其他草稿保留。删除另行确认。
5. 在任务中心查看逐条结果和诊断。取消只停止后续请求，不撤销远端变更。恢复仅核对未知写入，不自动重发；已成功记录不重复提交。

每个工作区对应服务器上的一家虚拟航空公司，不能把它改作另一家公司的工作区使用。重启后恢复缓存与草稿，需要重新测试连接，不自动提交。完全没有机型或机场可用于识别 VA 时，先在 Orwell 建立基础记录。

两个保存入口均会去掉 Client ID 的首尾空格，Secret 不会被裁剪。普通“保存连接设置”留空 Secret 会保留已有值；“仅更新 API 凭据”要求填写新的 Secret。保存失败不会部分更新凭据或工作区。

凭据失效导致任务暂停时，在设置页使用“仅更新 API 凭据”，填写新的 Client ID 和 Secret。该入口不会应用同页未保存的时刻设置，也不改变目标 VA 或任务。更新后重新连接，核验原 VA 后再恢复；未知写入仍仅回读核对。

刷新时先在临时数据中整理记录；读取、合并和保存全部成功后，才替换当前数据和查找信息。如果中途失败，不会只更新一部分机场数据。

## 冲突、删除与恢复

刷新时，程序会比较上次读取的原始数据、你正在编辑的草稿和服务器最新数据。如果双方修改的是不同字段，可以自动合并；如果改了同一个字段，就在“审阅冲突”中选择保留哪一方。服务器已删除、但本地仍有修改的记录不会自动重建。刷新后，原有数据对应的撤销历史会清除。

修改前再次读取远端，创建前检查疑似重复。部分创建操作先 POST 基本属性，保存返回 ID，再 PUT 补充属性。

提交前的查询临时失败时，记录仍是“待执行”，可以稍后重试。如果修改请求可能已经发出，或者无法查明服务器结果，就标记为“结果未知”，先核对再继续。

存在待执行或结果未知任务时，阻止新提交和刷新，避免重复变更。无返回 ID 的创建可在“核对未知结果”中输入在 Orwell 找到的候选 ID；核对失败后可重新打开并更正，候选历史会保留。离线时仅保存候选，连接后恢复任务再回读；匹配成功才绑定远端 ID，服务器已确认的 ID 不允许更换。已创建但补充更新中断的记录，可以在 Orwell 核对／补齐预期值后再次恢复核对。

机场和航线使用“软删除”，也就是服务器可能只是把记录标为删除。收到 204 响应只能说明请求被接收；之后查询返回 404，也不会直接当作删除成功。确认在 Orwell 核对后，可明确记录“人工确认”；此状态不会启用批量删除，也不算 API 自动验证成功。机型、飞机和航路为永久删除。应用检查本地引用，并在删除前刷新依赖；远端仍可能拒绝。

## 目前支持到什么程度

- CSV 表头和 API 使用的字段名可能不同，程序会按文档转换。不认识的 CSV 列会保留，但不会发给 API；暂不支持提交的字段会说明原因。
- 重量按 kg，日期与时刻按 UTC。分钟表格保留 API 原始秒数，日期保留原始小数秒；改变分钟或日期时沿用该精度。CSV 格式不变。
- PUT 只发送变更字段。机场 Container IDs 清空采用文档明确的 `[]`，其他未确认清空操作禁用。
- 飞机更换机型、已有航线 Fleet IDs 替换／追加／移除／清空，以及跨 Jumpseat 类型转换保持禁用。
- 航线和航路的起降机场不可在线修改；到期停用是独立的 End Date 修改，须满足日期关系校验。
- SimBrief 等复杂对象保存在原始 JSON 中，本轮不提供编辑器。
- 采用保守的进程共享预算，所有 VA 合计最多 60 次／分钟，429 遵守 Retry-After，不猜测 X-RateLimit-Reset 单位。在线失败不回退模拟模式。

## 本地数据与语言

设置页即时切换简体中文／英文，不重建页面或重发任务。官方字段、用户数据、CSV 和 API 内容不翻译。语言偏好对全部工作区生效。

软件名称在两种界面语言中均为 **FlightOps Desk**。新版使用独立运控图标；为兼容旧版，继续使用原数据目录，无需手动迁移工作区。

SQLite 默认位于 `%LOCALAPPDATA%/VamSysBatch/workspaces.db`，可通过 `VAMSYS_DATA_DIR` 指定隔离目录。凭据用当前 Windows 用户 DPAPI 加密。自动保存有 700 毫秒防抖，意外终止可能丢失最后一次尚未落盘编辑。没有远端事务回滚、删除恢复、团队服务器或自动同步。

本版本首次打开旧数据库时，会先保存一份完整备份，再升级到 v3。升级要么全部完成，要么保留原数据。升级前请关闭旧版；同一数据目录只允许一个新版实例。任务进度和待核对 ID 单独保存；确认服务器修改成功后，对应数据与任务成功状态会一起保存，避免只保存一半。关闭期间冻结编辑，保存失败恢复交互并保留草稿。任务中心只创建当前可见的列表内容，每次进度变化只更新相关记录和数量。升级后发生远端写入时，不可恢复迁移前备份继续任务。参见 [存储迁移与恢复说明](STORAGE-MIGRATION.md)。

CSV 导出保留未知列，仅处理变化记录，超过 10 MB 拆分，完成后标为“待到 Orwell 导入”，不是 API 成功。

## 大量数据和问题排查

新增航线和航路前，先按机场 ID 查找可能重复的记录。机场、机型和飞机的数据全部读取完成后，会建立快速查找表；确认新增、修改或删除成功后，也会更新这个表。同名但 ID 不同的记录不会被丢掉；检查飞机注册号是否重复时，会检查所有机型。

如果修改结果还不确定，查重时同时考虑修改前和修改后的名称等信息；删除结果不确定时，也仍把原记录视为可能存在。机场创建未核对成功时，后续机场创建显示待执行及原因，其他独立资源继续；请先核对未知结果，再恢复任务。恢复不重发未知写入，也不把输入候选 ID 当作核对成功。

每次在线任务结束会尝试将请求量、限流等待和保存统计写入数据目录的 `performance/<工作区ID>/<任务ID>/<执行ID>.json`，不包含凭据或请求内容。参见 [性能报告与复现方式](PERFORMANCE.md)。
